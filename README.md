## About this entry

The best office joke is the one every office worker recognises
instantly. This entry calls the printer jam a team building
exercise, which reframes the most dreaded piece of office equipment
as a bonding activity nobody signed up for. The punchline is the
second half: nothing bonds colleagues like shared trauma and a
blinking red light, because the trauma is real and the red light is
the only manager who ever shows up on time. The humour comes from
the bleak truth underneath the corporate language, and it lands on
the first read because everyone has stood in front of that printer.
The line stays one tight office joke, never wanders into another
topic, and stays well inside the two hundred character cap. The
program holds the line, checks it against that cap, and writes it to
/output/entry.txt exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one-line joke to `/output/entry.txt`.
